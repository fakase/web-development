# A. — Editorial Website

Website statis responsif dengan HTML, CSS, dan JavaScript murni.

## Menjalankan
1. Ekstrak ZIP.
2. Buka `index.html` di browser, atau gunakan ekstensi Live Server di VS Code.
3. Edit teks di `index.html`, warna di bagian `:root` dalam `style.css`, dan interaksi di `script.js`.

## Bagian
- Hero / pembuka
- Karya pilihan
- Tentang
- Jurnal
- Kontak
- Navigasi responsif untuk HP
- Animasi scroll reveal, progress bar, hover states

Font Google Fonts memerlukan koneksi internet. Ilustrasi hero dibuat dengan CSS, jadi tidak perlu aset gambar eksternal.
